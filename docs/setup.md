## v6 から v8 に上げる（v7 は反映していない場合）

v8 は、v7 の中身（教科を選ぶ・英語 全国精選2024・画像の拡大）に、**反映の自動化** を足した版です。GAS は **v7**、画面は **v8** です。

- **Cowork に任せる場合**：`docs/cowork-setup.md` → 1行送る。これで下の ①〜⑤ を全部 Cowork が行います。
- **手で行う場合**：すぐ下の「v6 から v7 に上げる」を、次の読みかえで行います。
  - `gas/Code.gs` は v8 の zip の中のもの（GAS v7）。**setup は実行しなくても、GAS が最初に呼ばれたときに自動で1回だけ実行します**（エディタで実行しても大丈夫です）。デプロイの説明は `v7`。
  - `index_v7.html` → `index_v8.html`、`ZE24_honsatsu.zip` → v8 の zip の中の `images/ZE24_honsatsu`、`ZE24_honsatsu.csv` → `data/ZE24_honsatsu.csv`。
  - 確認スクリプトで「画面の版」が v8、「サーバーの版」が v7 になれば完了です。

### GAS v7 で足したこと

- **setup の自動実行**：版が上がって最初に呼ばれたとき、setup（列やフォルダを足すだけ。データは消さない）を1回だけ実行します。
- **取り込み待ちフォルダ**：ドライブの「入試問題チェック ＞ 取り込み待ち」に、取り込み指示（`*.job.json`）と CSV を置いて合図（`runInbox`）を送ると、GAS が「本冊の登録 → 画像をつなぐ → 自己点検」を行い、報告を「取り込み済み」に書きます。
  - 合図にパスワードはいりません。できるのは、すでにドライブに置かれた取り込み指示の処理だけで、データを消す処理はありません。
  - 合図は 20 秒に1回・1時間に 40 回まで（それより多いと断ります）。

## v6 から v7 に上げる（25分）

v7 では、**教科（数学・英語）** を選べるようになり、英語の教材 **全国精選2024 ＞ 本冊・公立編（107問・23単元）** が入ります。数学のデータと記録はそのままです。

### ① GAS を入れかえる（GAS v6。再デプロイがいります）

1. スプレッドシートの「拡張機能」→「Apps Script」を開く。
2. 「コード.gs」を全部消して（**Ctrl + A** → **Delete**）、新しい `gas/Code.gs` を貼る → **Ctrl + S**。
3. 関数名の欄で **`setup`** を選んで **「▷ 実行」**。「準備ができました（v6）」と出れば OK。
   - 問題マスタに「マーク・音声URL・台本画像ID」、教材シートに「教科」の列が、右はしに足されます。
   - 教科が空の教材は **数学** として出ます（数学の行は、さわらなくて大丈夫です）。
4. **「デプロイ」→「デプロイを管理」→ ✏（編集）→ バージョン「新バージョン」**、説明に `v6` → **「デプロイ」**。
   - **「新しいデプロイ」は押さないでください**（URL が変わります）。

### ② 画像をドライブに入れる

1. `ZE24_honsatsu.zip` を展開する。中の `ZE24_honsatsu` フォルダに、`problems`（問題 107 枚）と `answers`（答えと解説 107 枚＋放送される英語 14 枚）があります。
2. ドライブの **入試問題チェック ＞ 問題画像** に、`problems` と `answers` を **フォルダごと** ドラッグする。

### ③ アプリを v7 にする

Cowork への指示文で `index_v7.html` を `index.html` として上書きし、教室長でログインする。

### ④ 英語を登録する（教室長画面）

1. **「本冊の登録」**：`ZE24_honsatsu.csv` を **メモ帳** で開いて全部コピーし、欄に貼る → **「確かめる」**。
   - 「107問（単元 23・小問 292）、まちがいはありません。レベルなし（生徒は全部の問題を解けます）　マーク 43問　音声ページ 14問」と出れば OK。
   - **教科「英語」**・教材名「全国精選2024」・セクション名「本冊・公立編」・出典が入っているのを確かめて **「保存する」**。
2. **「画像の自動登録」→「画像をつなぐ」**（1〜2分）。「問題画像 107 枚、解説・解答画像 107 枚、台本の画像 14 枚」をふくむ数が出れば OK。
3. **「問題の一覧」** で英語の23単元が「生徒に出る」、リスニングの単元に「音声 14・台本 14」と出れば完成。

`tools/console-check.js` を、教室長でログインした画面のコンソールで実行します。「教科」「英語 全国精選2024 本冊」「英語 1番（リスニング）」「英語の台本・マーク」が OK、「教室長の問題一覧」が 993 なら完了です。

> **あとで英語のレベル（選定表）ができたら**：`ZE24_honsatsu.csv` の「レベル」の列に ◎○△▲ を **全部の行に** 入れて、同じように「本冊の登録」で保存します。保存したときから、生徒は数学と同じようにレベルを選んで解けます。これまでの記録はそのまま残ります（レベルは全部入れるか、全部空のどちらかです。まざっていると保存できません）。
>
> **国立・私立編・直前チェックを足すとき**：問題ID を `ZE24-HS-001`（国立・私立編）、`ZE24-C-001`（直前チェック）の形にした CSV と画像で、同じように登録します。理科・社会・国語も、教科を選んで同じ形で足せます。

## 手順1　スプレッドシートを作る

1. Chrome で **https://drive.google.com** を開く。
2. 左上の **「＋ 新規」** →　**「Google スプレッドシート」** を押す。
3. 左上の「無題のスプレッドシート」を押して、`入試問題チェック データ` と打って Enter。

## 手順2　Apps Script（GAS）を開く

1. スプレッドシートの上のメニュー **「拡張機能」** → **「Apps Script」** を押す。
2. 左上の「無題のプロジェクト」を押して、`入試問題チェック` と打って **「名前を変更」**。

> 本文分析ノートの GAS とは **別のプロジェクト** です。本文分析ノートの GAS には何も貼らないでください。

## 手順3　プログラムを貼る

1. 左の **「コード.gs」** を押す。
2. 右の画面を1回押してから **Ctrl + A** → **Delete** で、最初からある文字を消す。
3. `nyushi-check` の `gas/Code.gs` をメモ帳で開き、**Ctrl + A** → **Ctrl + C**。
4. Apps Script にもどって右の白い所を押し、**Ctrl + V**。
5. **💾「プロジェクトを保存」**（Ctrl + S）を押す。

## 手順4　シートとフォルダを自動で作る（setup を1回だけ実行）

1. 「▷ 実行」の右の関数名の欄を押して、**`setup`** を選ぶ。
2. **「▷ 実行」** を押す。
3. 初めてのときは「承認が必要です」と出ます。
   1. **「権限を確認」** → 自分のアカウント。
   2. 「Google はこのアプリを確認していません」と出たら、左下の **「詳細」** → **「入試問題チェック（安全ではないページ）に移動」**。自分で作ったプログラムなので大丈夫です。
   3. **「許可」**（チェックボックスが出たら全部にチェック）。
4. 実行ログに **「準備ができました。」** と出たら成功です。
5. できているもの：
   - シート：**問題マスタ・教材・単元・レベル選択・生徒・講師・学習記録・宿題・Settings**
   - ドライブ：**入試問題チェック ＞ 元スキャン・問題画像・解説画像**（3つとも非公開のまま。共有はしないでください）
   - 問題マスタの「単元タグ」「公開」の列は、プルダウンになっています。

> setup は何回実行しても、入っているデータは消えません。

## 手順5　教室コードとパスワードを決める

**Settings** シートを開いて、B列に打ちます。

| key | 打つもの |
|---|---|
| classCode | 教室コード（生徒に教える。本文分析ノートと同じでもOK） |
| teacherPass | 講師パスワード（第2段階の講師画面で使う） |
| adminPass | 管理パスワード（教室長と紗耶佳先生だけが知る。教室長はこれだけでログインします） |
| sourceText | 出典の文。社名が決まったら `〇〇〇〇社` を書きかえる（アプリの更新はいりません） |

> パスワードは、最初にログインしたときに自動で暗号の形（ハッシュ）に置きかわり、打った文字は消えます。

## 手順6　生徒を入れる

1. 本文分析ノートのスプレッドシートの **Students** シートで、2行目から下の **A〜E列**（studentId・name・grade・pin・active）を選んでコピー。
2. こちらの **生徒** シートの **A2** を押して貼りつけ。列の並びが同じなので、そのまま入ります。
3. F列「担当講師」は空でかまいません（第2段階で使います）。
4. テスト生徒 T01（PIN 1111）・T02（PIN 2222）は、試作のあいだは残しておくと便利です。

## 手順7　ウェブアプリとして公開する

1. Apps Script の右上 **「デプロイ」** → **「新しいデプロイ」**。
2. 左の ⚙ →　**「ウェブアプリ」**。
3. 次のように選ぶ。
   - 説明：`v4`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. **「デプロイ」** → 出てきた **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）をコピー。
5. その URL を Claude に送る（`index.html` の `API_URL` に貼った版を作ります）。

> 「全員」にしても、教室コードと PIN・パスワードがないとデータは返りません。問題画像も、GAS がログインを確かめてから渡します。

### GAS を直したとき（2回目から）

**「デプロイ」→「デプロイを管理」→ ✏（編集）→ バージョン「新バージョン」→「デプロイ」** を押します。
この方法なら URL は変わらないので、`index.html` は直さなくてよいです。
（「新しいデプロイ」を押すと URL が変わってしまうので注意）

## 手順8　問題を入れる

計算・一行問題は「（参考）v2 から v3 に上げる」の **②〜④**、本冊は「v3 から v4 に上げる」の **②〜④** と同じです（GAS を新しく貼った場合、setup は手順4で済んでいます）。

## 手順9　動作を確かめる

`tools/console-check.js` の使い方は、そのファイルの一番上に書いてあります。教室長かテスト生徒 T01 でログインして実行し、すべて OK になれば準備完了です。
